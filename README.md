# Vixalt

Утилита для Arch Linux: поиск на YouTube из терминала и показ иконки проекта.

## Установка

### AUR

    yay -S vixalt
    # или
    paru -S vixalt

## Использование

    vix                     # показать иконку
    vix lofi hip hop        # поиск на YouTube

## Зависимости

- bash
- xdg-utils
- python

Опционально:
- chafa — для показа картинок в терминале
- kitty — для Kitty graphics protocol
